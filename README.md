Predicting employee attrition with 98% accuracy using Random Forest and customized threshold optimization.

This project focuses on predicting employee attrition (churn) to help the HR department take proactive measures. By analyzing employee data, I developed a machine learning pipeline that identifies high-risk employees with exceptional accuracy.

By shifting the decision threshold to 0.23, the model became significantly more sensitive to "at-risk" employees. For the business, this means:
Proactive Retention: Identifying 97% of employees likely to leave.
Efficiency: Minimizing false alarms, allowing HR to focus resources on the right individuals.
Financial Savings: Reducing turnover costs by enabling early intervention.
